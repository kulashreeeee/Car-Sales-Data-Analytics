Car Sales Data Analytics

## Project Overview
This project analyzes car sales data using Microsoft Power BI.

## Tools Used
- Microsoft Power BI
- Excel
- Power Query

## Key Analysis
- Total car sales
- Sales by brand
- Sales by model
- Sales by year
- Sales by location
- Revenue analysis

## Dashboard
The Power BI dashboard provides interactive visualizations
to understand car sales performance and trends.

## Files
- Car Dashboard.pbix.zip – Power BI dashboard (compressed ZIP file)
- Cardata.xlsx - Processed dataset
- UNCLEANED CAR DATA.xlsx - Raw dataset
